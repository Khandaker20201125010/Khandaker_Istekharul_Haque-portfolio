# My-Portfolio 

- Live Link - https://khandaker-istekharul-haque-portfoli.vercel.app/

This is the **frontend** for my personal portfolio website, built using **Next.js**, **TypeScript**, and **Tailwind CSS**. It showcases my projects, blog posts, and personal information, while providing a private dashboard for the portfolio owner to manage content.

---

## 🚀 Features

### Public Features
- **About Me Section**: Displays personal information, work experience, and skills.
- **Projects Showcase**: List of personal projects with thumbnail, live link, repo links, description, and features.
- **Blog Management (Public View)**: View all blog posts and individual blog pages.
- **Responsive UI**: Fully responsive design for all device sizes.
- **Animations & Interactions**: Smooth hover effects, transitions, and scroll animations.

### Private Features (Owner Only)
- **Authentication**: Secure JWT-based login for the portfolio owner.
- **Dashboard**: Private dashboard to manage projects, blogs, and other content.
- **Blog Management (CRUD)**: Create, read, update, and delete blogs.
- **Project Management**: Add, update, or remove projects from the showcase.

---

## 🛠 Tech Stack

**Frontend**
- [Next.js](https://nextjs.org/) – React framework for SSR & SSG
- [TypeScript](https://www.typescriptlang.org/) – Type safety
- [Tailwind CSS](https://tailwindcss.com/) – Styling & responsive utilities
- [Framer Motion](https://www.framer.com/motion/) – Animations and transitions
- [React Hot Toast](https://react-hot-toast.com/) – Notifications
- [Lucide Icons](https://lucide.dev/) – Icon components

**Backend (Integration)**
- Node.js + Express.js
- Prisma + PostgreSQL or MongoDB + Mongoose
- JWT & bcrypt for authentication
- API endpoints for projects, blogs, and authentication
